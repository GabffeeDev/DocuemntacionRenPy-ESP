## Herramientas para desarrolladores

Ren'Py incluye herramientas útiles para depurar, probar y acelerar el desarrollo de novelas visuales:

- **Menú de desarrollador**: permite acceder a opciones de depuración durante la ejecución.
- **Recarga rápida**: útil para probar cambios sin reiniciar toda la partida.
- **Lint**: revisa errores comunes en scripts, imágenes y recursos.
- **Consola y depuración**: facilita inspeccionar variables, ejecutar comandos y detectar fallos.
- **Modo de pantalla completa / ventana**: ayuda a ajustar la interfaz durante pruebas.

Para sacar más provecho de estas herramientas, revisa la documentación oficial de Ren'Py y prueba tus cambios con frecuencia mientras desarrollas.

Dato curioso: Ren'Py usa Python para la lógica y un lenguaje de script propio para contar historias, lo que lo hace muy cómodo para prototipar novelas visuales.
